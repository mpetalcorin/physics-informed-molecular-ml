# Physics-Informed Molecular ML**Quantum chemistry, Δ-learning, protein–ligand affinity prediction, uncertainty quantification, and molecular machine learning for small-molecule drug discovery**![Physics-Informed Molecular ML](assets/physics_informed_molecular_ml.png)## Overview`physics-informed-molecular-ml` is an end-to-end scientific machine learning portfolio project that integrates principles from **quantum chemistry, molecular modelling, cheminformatics, protein–ligand interactions, and machine learning**.The project demonstrates how relatively inexpensive molecular calculations can be combined with machine learning to approximate higher-level quantum chemical predictions, while also integrating molecular and protein-context features for prediction of protein–ligand binding affinity.The workflow is designed to demonstrate capabilities relevant to modern AI-enabled drug discovery:- Python scientific programming- molecular descriptors and cheminformatics- quantum chemistry concepts- xTB-to-DFT Δ-learning- protein–ligand affinity modelling- PyTorch neural networks- statistical learning- uncertainty quantification- applicability-domain analysis- model interpretability- reproducible computational workflows- interfaces for xTB, Psi4, PySCF, and ORCA- scalable scientific-software designThe current repository uses a **synthetic, literature-benchmarked molecular dataset** to provide a completely reproducible demonstration without exposing proprietary molecular or experimental data.---# Scientific MotivationHigh-level quantum chemical calculations can provide accurate molecular energies and electronic properties, but their computational cost limits their use across very large chemical libraries.A useful strategy is therefore:```textLow-cost molecular calculation            ↓        xTB-like energy            ↓Machine learning correction            ↓          ΔE            ↓Estimated high-level DFT energy```The machine learning model learns\[\Delta E = E_{\mathrm{DFT}} - E_{\mathrm{xTB}}\]and predicts\[E_{\mathrm{DFT}}^{\mathrm{predicted}}=E_{\mathrm{xTB}}+\Delta E_{\mathrm{ML}}\]This approach is commonly called **Δ-learning**.The same physics-informed philosophy can be extended to molecular recognition:```textMolecular structure        +Quantum descriptors        +Physicochemical properties        +Protein context        +Interaction features        ↓Machine learning model        ↓Protein–ligand affinity        +Prediction uncertainty```Rather than treating molecular prediction as a purely statistical problem, the workflow incorporates physically meaningful representations of molecular energetics, polarity, electronic structure, and intermolecular interactions.---# Project ObjectivesThe project addresses five interconnected questions.### 1. Can machine learning correct a lower-cost molecular energy estimate?A Δ-learning model predicts the difference between simulated xTB-like and DFT-like molecular energies.### 2. Which molecular properties influence the correction?Electronic and physicochemical descriptors are analysed using feature importance and correlation analysis.### 3. Can molecular and protein-context information predict binding affinity?Multiple regression and machine learning algorithms predict synthetic protein–ligand `pKd`.### 4. How reliable are individual predictions?Prediction uncertainty and applicability-domain analyses identify observations where model confidence should be lower.### 5. Can the workflow be transferred to real quantum-chemistry infrastructure?The notebook includes interfaces and design patterns for integration with:- xTB- Psi4- PySCF- ORCA- PyTorch- JAX---# Workflow```text                SMALL MOLECULES                       │                       ▼             Molecular descriptors                       │ synthetic but designed to occupy biologically and chemically plausible ranges informed by peer-reviewed molecular-modelling literature.Example variables include:| Category | Example variables ||---|---|| Molecular size | molecular weight, heavy atom count || Lipophilicity | logP || Polarity | topological polar surface area || Hydrogen bonding | H-bond donors, H-bond acceptors || Flexibility | rotatable bonds || Quantum properties | HOMO energy, LUMO energy, HOMO–LUMO gap || Electrostatics | dipole moment || Molecular energetics | xTB-like energy, DFT-like energy || Protein context | protein-family representation || Interaction features | hydrogen-bond and hydrophobic interaction terms || Binding | synthetic pKd |The dataset is **not experimental clinical or proprietary pharmaceutical data**.It is intended for methodological demonstration, education, portfolio development, and reproducible scientific computing.---# Δ-LearningThe first modelling problem predicts the correction between lower-cost and higher-level molecular energies.For molecule \(i\),\[\Delta E_i = E_{DFT,i} - E_{xTB,i}\]The learned prediction becomes\[\hat{E}_{DFT,i} = E_{xTB,i} + \hat{\Delta E}_i\]In the reproducible synthetic experiment, the uncorrected xTB-like energy has an error of approximately:```textMAE ≈ 1.8 kcal/mol```After Δ-learning, the error falls to approximately:```textMAE ≈ 0.45 kcal/mol```These results demonstrate the **principle** of ML-based quantum correction.They must not be interpreted as validation against experimentally measured energies because the current dataset is synthetic.---# Protein–Ligand Affinity ModellingThe second major task predicts protein–ligand affinity using a combination of:- molecular descriptors- electronic properties- interaction descriptors- protein context- physicochemical propertiesSeveral model classes are compared:```textLinear / Ridge regression        ↓Random Forest        ↓Gradient Boosting        ↓PyTorch multilayer perceptron```Evaluation includes:- RMSE- MAE- coefficient of determination, \(R^2\)- Pearson correlation- residual analysis- predicted-versus-observed plotsWhere possible, evaluation is performed using **protein-aware splitting** rather than relying exclusively on random train/test partitioning.This reduces the risk of obtaining artificially optimistic performance through closely related protein–ligand examples appearing in both training and test sets.---# Machine Learning Models## Ridge RegressionProvides an interpretable regularized linear baseline.Useful for answering:> How much predictive information is available from approximately linear relationships?## Random ForestCaptures nonlinear effects, descriptor interactions, threshold behaviour, and heterogeneous molecular relationships.## Gradient BoostingProvides a strong tabular-data model that can learn complex nonlinear molecular relationships.## PyTorch Neural NetworkA multilayer perceptron demonstrates neural-network development using **PyTorch**, including standardized molecular features, nonlinear hidden layers, backpropagation, validation monitoring, and held-out testing.The architecture can subsequently be replaced by molecular graph neural networks, message-passing neural networks, equivariant neural networks, or other geometric deep-learning architectures.---# Physics-Informed FeaturesInput features flexibilityinteraction strengthprotein context```These provide a bridge between:```textPhysical chemistry       ↓Molecular representation       ↓Machine learning       ↓Drug-discovery with unusually high uncertainty can be flagged for additional quantum calculations, experimental measurement, structural review, or exclusion from automated prioritization.---# Applicability DomainMachine learning models are most reliable when predictions are made for molecules sufficiently similar to the model's training domain.The workflow therefore estimates an **applicability domain** to distinguish higher-confidence in-domain predictions from lower-confidence out-of-domain predictions.---# Model InterpretationPermutation feature importance is used to investigate which molecular properties contribute most strongly to predictions.The analysis asks questions such as:- Are electronic properties contributing?- Are molecular-size effects dominating?- How important is lipophilicity?- Do protein-context variables improve affinity prediction?- Are interaction terms more informative than generic molecular descriptors?Interpretability is treated as part of model validation rather than as an optional visualization.---# VisualizationsThe project generates a series of publication-quality figures:- `outputs/01_eda_overview.png` — exploratory **Machine learning is most useful when it complements physical knowledge rather than replacing it.**Quantum chemistry provides physically meaningful information about molecular electronic structure. Machine learning provides computational scalability. Protein structural information provides biological context. Uncertainty quantification provides information about prediction reliability.Together:```textPhysics   +Chemistry   +Structural biology   +Machine learning   +Uncertainty   ↓Better molecular decisions```---# LimitationsThis repository is a methodological demonstration.1. The current molecular dataset is simulated.2. DFT-like and xTB-like energies are synthetic rather than outputs from actual quantum calculations.3. Protein–ligand affinity values are simulated.4. Reported model performance therefore does not constitute experimental validation.5. Real drug-discovery performance would depend strongly on molecular diversity, assay quality, protein-family distribution, structural accuracy, and train/test splitting strategy.6. Prospective experimental validation would be required before using predictions for scientific decision-making.These limitations are intentional and explicitly stated to distinguish **method demonstration** from **validated drug-discovery modelling**.---# Next Development StagesPlanned extensions include:- RDKit molecular graph generation- real xTB calculations- PySCF calculations- Psi4 DFT calculations- ORCA integration- QM9 benchmarking- ChEMBL bioactivity data- PDBbind protein–ligand complexes- molecular graph neural networks- message-passing neural networks- E(3)-equivariant neural networks- conformer ensembles- molecular dynamics-derived descriptors- active learning- Bayesian uncertainty- calibration analysis- virtual screening- prospective molecular ranking- containerized deployment- cloud/HPC execution---# Scientific BackgroundLarge quantum-chemistry datasets such as QM9 have enabled systematic development of machine learning models for molecular energies and properties.Protein–ligand affinity datasets such as PDBbind have similarly supported benchmarking of structure-based machine learning methods.However, careful validation is essential because molecular and protein similarity between training and test sets can produce overly optimistic estimates of model generalization.The present project therefore emphasizes prediction, physical interpretation, uncertainty, applicability domain, and careful validation rather than predictive performance alone.---# Selected Peer-Reviewed ReferencesRamakrishnan, R., Dral, P.
